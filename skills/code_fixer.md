# Code Fixer Skill

When modifying C++ code files:
1. Always maintain proper standard compliance (C++17/20/23).
2. Prefer surgical edits and preserve original style and comments.
3. Verify compilation clean state after editing header and source files.
4. Ensure all header files use `#pragma once` guard.
