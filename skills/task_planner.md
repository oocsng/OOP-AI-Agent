# Task Planner Skill

When given a complex or multi-step prompt, follow these directives:
1. Break down the user prompt into distinct, ordered sub-goals.
2. Identify which tools are needed for each step before executing.
3. Verify intermediate output after each tool execution before moving to the next step.
4. Provide a clear summary of progress at each phase.
